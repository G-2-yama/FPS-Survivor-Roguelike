## 開発環境
### Unity
- バージョン：6000.3.11f1
### Git
1. 各開発者は「<作業タグ>/<作業内容>」というブランチ名で開発
    - 例えばAという新規機能を追加する場合，ブランチ名は「feature/A」となる．
    - タグは以下の通り  
        1. 新規機能追加：**feature**
        2. 仕様変更：**modify**
        3. コード整理：**clean**
        4. バグ修正：**fix**
        5. 致命的なバグ修正：**hotfix**
2. プルリクエスト先は，「**main**」として，「**main**」からブランチを切る．
3. エディタ用のディレクトリは追跡させない．
    - vscode，Visual Studio 以外のエディタを使っている人は，自分で.gitignoreに追加する．
4. コミットメッセージは，可能な限り以下のルールに従う．
    - 1行目に「[<タグ>]<概要>」(2行目を空行にして，3行目以降にコミットの詳細)を書く．
        - 例：  
        [add]操作性向上のため，A機能を実装  
          
          操作をする際にxxという障害があり，その障害を取り除くためにAという機能を実装．
        - タグは以下の通り  
            1. 新規機能追加：**add**(**feat**でも可)
            2. 機能修正・仕様変更：**modify**
            3. コード整理：**clean**
            4. バグ修正：**fix**
            5. 致命的なバグ修正：**hotfix**
    - ただし，己の哲学，美学に従っていて，他者が見て分かりやすいものであればこの限りではない．
