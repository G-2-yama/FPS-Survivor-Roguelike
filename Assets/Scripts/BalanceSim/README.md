# バランス調整シミュレータ

シミュレータ自体の不具合や、足りない機能・おかしい挙動に気づいたら、 neriame-code に連絡してください

やりたいことに合う手順を「やりたいこと別の手順」から選ぶ。各機能の細かい説明は後半の「機能の説明」にある

## やりたいこと別の手順

### 今のゲームの値のまま回す

1. Project ウィンドウで `Assets/Datas/BalanceSim/BalanceSimSettings.asset` を選ぶ。
   - 設定を変えて残したいときは、このアセットを複製するか、`Assets > Create > BalanceSim > Settings` で新しく作る。
2. Inspector で設定を確認する。各項目の意味は、項目名にマウスを乗せると出る説明を見る(大体の場合は既定のままで大丈夫なはず)
   - 「Target Scene」には値を読み出すシーンを入れる
3. Inspector の一番下の「実行」
4. 終わると結果のウィンドウが自動で開く。閉じた後は `Tools > BalanceSim > 結果` で開き直せる

Console にはクリア率、死亡時刻、最終レベルと撃破数の平均などの要約などが出る(エラーが出たら言ってください)

どの値をゲームから読むかは「使われる値」、結果のウィンドウの見方は「結果のウィンドウ」

### 特定の値を変えて試す

シーンやアセットを書き換えずに、シミュレーションで使う値だけを変える

1. `Assets > Create > BalanceSim > Values` で数値SO を作る
2. 数値SO の Inspector で「Overrides」の + を押して行を足し、1行ごとに対象・項目・値を設定する（選び方は「数値SO」）
3. BalanceSimSettings の「Values」欄に作った数値SO を入れ、「実行」を押す

### どの値が結果に効くか調べる

調整の候補になる値がたくさんあり、どれをいじるのが効果的か知りたいとき

1. `Assets > Create > BalanceSim > Sweep` で探索SO を作る
2. 探索SO の Inspector で、作り方の種類を OneAtATimeSweep（1行ずつ）にする
3. 「Axes」の + を押して、効くかどうか調べたい値を1行ずつ足し、対象・項目・範囲（最小・最大・刻み）を設定する。対象と項目の選び方は数値SO と同じ
   - 全武器の威力など、たくさんの値を同じ割合で動かしたいときは「Groups」の1行にまとめる（「まとめて倍率で振る（Groups）」）
   - 振らずに固定しておきたい値は、数値SO にして「Fixed Values」に入れる
4. BalanceSimSettings の「Values」欄に探索SO を入れる。Inspector に出る通り数×回数と所要時間の目安を見て、長すぎれば範囲や刻みを見直す（「かかる時間の目安と注意」）
5. 「実行」を押す
6. 結果のウィンドウ上部で「値ごと」を選び、「指標」で見たい値を選ぶ
7. 上に並んだグラフほど、その指標によく効いている値。線がほぼ平らな値は調整の候補から外してよい。線が破線（何も変えない基準の通り）のどちら側にあるかで、今の値から変えたときの上下が分かる（見方の詳細は「値ごと」）
   - 例: 「クリア率が高すぎるので下げたい。どの値をいじるのが効くか」→ 指標をクリア率にして、上に並んだグラフの値を調整の候補にする
   - 例: 「ある武器が進化しにくい」→ 指標をその武器の進化率にして、どの値で進化率が上がるかを見る

効果的な値が分かったら、それを2〜3個に絞って「2つの値をどれだけ変えるか決める」に進む

### 2つの値をどれだけ変えるか決める

効果的な値が絞れていて、どちらをどれだけ変えるかを決めたいとき

1. 探索SO の「Axes」（と「Groups」）を、効く値の2〜3個だけにする
2. 作り方の種類を選ぶ
   - GridSweep（格子）: 全組み合わせを試す。振る値が少ないとき。10000 通りを超えると実行できない
   - RandomSweep（ランダム）: 組み合わせを「Case Count」の数だけ選んで試す。全組み合わせだと多すぎるとき
3. BalanceSimSettings の「Values」欄に探索SO を入れ、所要時間の目安を確認して「実行」を押す
4. 結果のウィンドウ上部で「組み合わせ」を選び、「横軸」「縦軸」に2つの値を選ぶ。色の変わり方から2つの値の関係を見て、狙いの範囲を決める（見方の詳細は「組み合わせ」）
5. 「表」で、見出しを押して並べ替え、目標（例: クリア率 60〜70%）に近い組み合わせを探す
6. その行をダブルクリックして時系列のグラフを開き、何秒ごろに死んでいるか、いつ進化しているかなど、中身を確かめる

### 目標のクリア率になる値を探す

動かす値は決まっていて、クリア率が目標になる値を知りたいとき

1. `Assets > Create > BalanceSim > Sweep` で探索SO を作り、作り方の種類を TargetClearRateSweep（目標のクリア率）にする
2. 動かす値を「Axes」に1行だけ足す。複数の値をまとめて動かしたいときは、Axes には足さず「Groups」の1行に入れる（Axes と Groups の合計が1行でないと実行できない）
3. 「Target Clear Rate」に目指すクリア率（%）を入れる。「Tolerance」「Points Per Round」の意味は「組み合わせの作り方」
4. BalanceSimSettings の「Values」欄に探索SO を入れ、「実行」を押す
5. 完了時のログに、止まった理由と、目標に一番近い値が出る。試した値は全部まとめの表に入る
   - 止まった理由が「最小でも最大でもクリア率が目標の同じ側にある」なら、範囲を広げてやり直す

### 結果を保存して人に渡す

- 結果のウィンドウ右上の「保存」で、プロジェクト直下の `BalanceSimResults/` に JSON で保存する（git には入らない。共有したいときは Discord などでファイルを渡す）
- 「開く」で保存した結果を読み込む
- 保存しなかった結果は、次の実行で上書きされる

## 各機能の詳細

### 使われる値

- 敵の出現（EnemyGenerator と PhaseData）、敵のプレハブ、プレイヤー、最初に持っている武器（プレイヤーの武器スロット）、レベルアップの選択肢、制限時間、地形などを読む
- 数値を変えて試すときは、「数値SO」を使う。**シーンやアセットを書き換える必要はない**
- 「武器は HG だけで試したい」のように、武器などの参照を入れ替える条件は数値SO では変えられない(もし必要なら対応するかも)。シーンやアセットをそのように変えて実行し、試した後は元に戻すように

### 数値SO

変えたい値を「数値SO」にまとめ、設定に入れて実行する。数値SOはシミュレータ専用の設定値になるのでゲームのアセットやシーンは書き換えない

「Overrides」の1行ごとに次を設定する

- 対象: 値を変えたいアセット（PhaseData、WeaponData、EnemyConfig など）、プレハブ、またはシーン上のオブジェクトをドラッグする。GameObject を入れたときは、右の一覧でコンポーネントを選ぶ
- 項目: ボタンを押すと、Inspector と同じ名前で項目が並ぶ（括弧内は今の値）。選べるのは数値と真偽値だけ
- 値: シミュレーションで使う値。右に今のゲームの値が出る

注意

- 数値SO に書いていない値は、これまでどおりゲームから読む(BalanceSimDefaultValuesは全てが空＝規定値のままシミュレーションする)
- 対象シーンを開いたまま、シーン上の値を上書きして実行すると、シーンに「*」（変更あり）が付くが、値は元に戻っているので心配なく
- 同じ項目を2行で上書きしたときは、下の行の値を使う（警告が出る）

### 探索SO

値を範囲で振って、組み合わせごとの結果を比べる。`Assets > Create > BalanceSim > Sweep` で作る

Inspector の項目

- Fixed Values: 振らずに固定しておく値の数値SO（空ならゲームの値のまま）
- Axes: + を押して行を足し、1行ごとに対象・項目・範囲（最小・最大・刻み）を設定する。対象と項目の選び方は数値SO と同じ
- Groups: 複数の値に同じ倍率を掛けて、まとめて1つの振る値として扱う（「まとめて倍率で振る（Groups）」）
- 作り方の種類: 組み合わせの作り方を選ぶ（「組み合わせの作り方」）。種類を変えても Axes と Groups はそのまま残る
- 行ごとの通り数と、全体の通り数が Inspector に出る

BalanceSimSettings の「Values」欄に探索SO を入れて実行すると、組み合わせ1通りごとに「Run Count」回ずつ回す

- 設定の Inspector に、通り数×回数と、前回の速度から見た所要時間の目安が出る
- 実行中は「中止」で止められる。それまでに終わった組み合わせの結果が表示される

#### 組み合わせの作り方

| 種類 | 試す組み合わせ | 通り数 | 向いている使い方 |
|---|---|---|---|
| GridSweep（格子） | 全行の値の全組み合わせ | 各行の通り数の掛け算。10000 通りを超えると実行できない | 振る値が少ないとき。値どうしの組み合わせの効果まで見たいとき |
| OneAtATimeSweep（1行ずつ） | 何も変えない基準の1通りと、1行だけを動かして他は変えない通り | 1 + 各行の通り数の合計 | 振る値が多いとき、まずどの値が結果に効くかを調べる |
| RandomSweep（ランダム） | 全行を同時にばらばらに動かした組み合わせを、Case Count の数だけ | Case Count で決める | 振る値が多く、組み合わせの効果も見たいとき |
| TargetClearRateSweep（目標のクリア率） | 1行の値を、クリア率が目標に近づくように絞り込みながら | 止まるまで分からない。Inspector には最大の通り数が出る | 動かす値は決まっていて、目標のクリア率になる値を知りたいとき |

- 1行ずつ: 表では、その通りで動かしていない行の欄は「-」（ゲームの値、または Fixed Values の値のまま）になる。基準の通りは「振った値: なし（基準）」と出る
- ランダム: 各行の候補は格子と同じ（最小から最大まで刻みずつ）。行ごとに、どの候補もなるべく同じ回数ずつ出るように選び、同じ組み合わせは出さない
  - Seed が同じで行も同じなら、同じ組み合わせになる。別の組み合わせを試したいときは Seed を変える
  - 全組み合わせが Case Count 以下のときは実行できない（格子で全部試す）
- 目標のクリア率: 振る行（Axes と Groups の合計）を1行だけにして使う。複数の値をまとめて動かしたいときは Groups の1行に入れる
  - 設定: Target Clear Rate（目指すクリア率 %）、Tolerance（許容幅。既定 ±2 ポイント）、Points Per Round（1回に試す値の数。既定 5）
  - 1回目は、行の最小と最大を含めて等間隔に試す。2回目からは、クリア率が目標をまたぐ隣り合った2つの値の間を、等間隔に試す
  - 止まる条件: 目標から許容幅以内の値が出た／刻みより細かく絞れない／最小でも最大でもクリア率が目標の同じ側にある（範囲を広げる）
  - 値を上げるとクリア率が上がるか下がるかは問わない。ただし、クリア率が上下に揺れながら変わる値では、目標をまたぐ区間が複数でき、警告を出したうえで目標に一番近い値を含む区間を選ぶ
  - クリア率は Run Count 回の割合なのでぶれる（100 回で 50% 付近なら約 ±5 ポイント）。許容幅をこれより狭くしても、当たった値は偶然のことがある

#### まとめて倍率で振る（Groups）

全武器の威力、全敵の HP など、たくさんの値を同じ割合で動かしたいときに使う

- 1行に、名前（結果の表の列名）、倍率の範囲（最小・最大・刻み）、対象の一覧を設定する。1行が Axes の1行と同じく1つの振る値になり、どの作り方でも使える
- 対象の値に倍率を掛ける。掛ける元の値は、Fixed Values に同じ項目があればその値、無ければゲームの値。整数の項目は四捨五入する
- 選べる項目は数値だけ（真偽値は選べない）
- 対象の足し方
  - 1つずつ: 「対象」の一覧の + で足し、対象と項目を選ぶ
  - まとめて: 一覧の下の枠に、Project ウィンドウやヒエラルキーで選んだものをまとめてドラッグする。一覧の最後の行と同じ名前の項目を持っていれば、その項目が選ばれる。先に1つ目の対象の項目を選んでからドラッグするとよい
  - プレハブや GameObject をドラッグしたときは、その項目を持つコンポーネントを選ぶ（無ければ最初のコンポーネント。必要なら右の一覧で選び直す）

#### かかる時間の目安と注意

- かかる時間はおおよそ「通り数 × 回数」に比例する
- 目安（12スレッドの PC、Time Step 0.04、ほぼ毎回クリアする条件で測った値）: 100回で1通りあたり約3.8秒、10回で約0.5秒
  - 100通り × 100回で約6分、10000通り × 100回で約11時間
  - Time Step 0.02 だと約2倍かかる。途中で死ぬ回が多い条件なら短く、敵が多く残る条件なら長くなる。PC のコア数でも変わる
- 大きな探索をするときは、設定の「Keep Run Details」（各回の記録を残す）を外す
  - オンのとき、結果は1通りあたり約0.8MB（100回、Sample Interval 1秒のとき）。数千通りを超えると数GBになり、Unity が落ちたり、結果を開けなかったりする可能性がある（未検証）
  - 外すと、組み合わせごとの集計（まとめの表の数値と、平均だけの粗いグラフ）だけを残し、1通りあたり数KBになる。グラフの点の間隔は「Summary Sample Interval」（既定 30秒）
- 途中から再開はできない。中止や再コンパイルで止まったときは、それまでに終わった組み合わせの結果だけが残る
- まず通り数と回数を少なくして試し、範囲を絞ってから細かく振るのがおすすめ

### 結果のウィンドウ

探索の結果は、最初に「まとめ」（組み合わせごとのクリア率、死亡時刻・最終レベル・撃破数の平均、武器ごとの進化率と進化時刻の平均）が出る
進化の列は、どの組み合わせでも1回も進化しなかった武器の分は出さない。進化時刻の平均は、進化した回だけの平均
まとめは、ウィンドウ上部の「表」「値ごと」「組み合わせ」で表示を切り替える。「値ごと」「組み合わせ」は、上の「指標」で選んだ値（クリア率、撃破数の平均、武器ごとの進化率など）をグラフにする

| 表示 | 答える問い | 向いている探索 |
|---|---|---|
| 値ごと | どの値が結果に効くか。その値を上げ下げすると結果がどう変わるか | どれでも。特に1行ずつ・ランダム |
| 組み合わせ | 2つの値の組み合わせで結果が変わるか。どの組み合わせが狙いに近いか | 格子。ランダムは通り数が多いとき |
| 表 | 狙いに一番近い組み合わせはどれか | どれでも |

#### 値ごと

振った値1つにつきグラフ1枚。横軸がその値、縦軸が指標

- 点が1通り。線は、その値が同じ通りの平均
- グラフは「平均の差」（線の最大と最小の差）が大きい順に並ぶ。上にあるほど、その指標によく効いている値。縦軸の目盛りは全部のグラフで同じなので、傾きの大きさをそのまま比べてよい
- 見方
  - 線が右上がり: その値を上げると指標が上がる。右下がりはその逆
  - 線がほぼ平ら: その値は、その指標にほとんど効いていない。調整の候補から外してよい
  - 途中で線が急に曲がる: そこを境に効き方が変わる。その手前あたりが調整の狙い目
  - 同じ値で点が縦に大きく散らばる（格子・ランダム）: 他の値との組み合わせで結果が変わっている。「組み合わせ」で2つの値の関係を見る
  - 1行ずつの探索では、他の値を動かしていない基準の通りを破線で出す。線が破線のどちら側にあるかで、今の値から変えたときの上下が分かる
- 点にマウスを乗せると、その通りで振った値が出る。ダブルクリックでその組み合わせの時系列のグラフを開く

#### 組み合わせ

「横軸」「縦軸」で選んだ2つの値の組み合わせごとに、指標の平均を色で出す（色と値の対応は下の帯）。マスの数字は平均と通りの数

- 見方
  - 色が左右にだけ変わる: 横軸の値だけが効いている。上下にだけ変わるなら縦軸の値だけ
  - 色が斜めに変わる: 両方が効いている。同じ色のマスをたどると、「片方を上げたら、もう片方をどれだけ下げれば同じ結果になるか」が分かる
  - 一部の行や列だけ色の変わり方が違う: 組み合わせの効果がある（例: 敵の数が多いときだけ武器の威力が効く）。片方ずつ調整すると狙いを外しやすい
- 該当する通りがないマスは灰色
- ランダムでは1マスあたりの通りの数が少なくなりやすい。通りの数が1〜2のマスは偶然の影響が大きいので、色の差を信じすぎない
- 1マスが1通りのときは、ダブルクリックでその組み合わせの時系列のグラフを開く
- 1行ずつの探索では、2つの値を同時に動かした通りがないので使えない

#### 表

- 見出しを押すとその列で並べ替える。狙い（例: クリア率 60〜70%）に近い行を探すのに使う
- 行をダブルクリックすると、その組み合わせの時系列のグラフを開く。何秒ごろに死んでいるか、いつ進化しているかなど、まとめの数字だけでは分からない中身を確かめる

#### まとめを見るときの注意

- 点やマスの値は、1通りあたり「Run Count」回の平均。回数が少ないと偶然で上下する。例えば 10 回ならクリア率は 10% 刻みでしか動かない
- 差が小さいときは、Run Count を増やして同じ傾向が出るか確かめる
- 格子・ランダムの「値ごと」の線は、他の値をならした平均。他の値をどの範囲で振ったかによって線の高さは変わる

#### 組み合わせごとのグラフ（時系列）

ウィンドウ上部の ◀ ▶ で、組み合わせごとのグラフを表の並び順に切り替える。「まとめ」ボタンでまとめに戻る

横軸は経過時間（秒）。欄ごとに、全実行の平均を線で、p10〜p90 の範囲を帯で表示（割合の欄は線だけ。「Keep Run Details」を外して実行した結果は、どの欄も平均の線だけ）
p10〜p90 は「下位 10% と上位 10% を除いた範囲」で、実行ごとのばらつきの大きさを表す
グラフにマウスを乗せると、その時刻の値が凡例に出る

| 欄 | 内容 |
|---|---|
| レベル | プレイヤーのレベル |
| 撃破数 | 倒した敵の数（Enemy を持つ敵だけ。Ball や敵の弾は数えない） |
| HP | プレイヤーの HP |
| 生存率 | その時刻まで生きている回の割合 |
| 場に残っている数 | EnemyGenerator ごとの敵の数。「生存数」は実際に場にいる数、「リスト数」はゲームが上限の判定に使うリストの数（下の Ball の項を参照） |
| 進化率 | その時刻までに進化した回の割合。進化先の武器ごとに出る |

- 死んだ回は、死んだ時点の値（レベル・撃破数など）のまま、最後まで平均に含まれる
- 系列が複数ある欄では、全部 0 の系列は表示しない

### プレイヤーの動き方（調整したいものがあれば言ってもらえれば）

- 常に走る。近くの敵が少ない方向へ逃げ、行き止まりを避ける（Inspector の「プレイヤーの仮定」で調整できる）
- 手動の武器は、一番近い敵が射程（「Fire Range」）に入っている間だけ撃つ。左右のメインは両方撃つ
- 狙いは一番近い敵の方向。撃つたびに「Aim Error」の角度の範囲でずれる
- アビリティは使えるようになったらすぐ使う
- レベルアップは、Inspector の「レベルアップの選び方」で選んだ方法で選ぶ（ランダム、または強化の優先順）

### 簡単にしていること

- ステージを上から見た平面として扱い、高さは無視する
- グレネード・火炎瓶は地面に落ちたら爆発、空爆は真上から落ちて着地したら爆発する。落ちる途中で敵に当たらない
- 敵どうしは押し合わない
- 敵に触れたときのダメージは、触れ始めの1回だけ
- 敵の当たり判定は円、斬撃などの攻撃範囲は長方形で扱う
- Orbit の弾は、毎回同じ角度から回り始める

### そのまま再現しているゲームの挙動（バグの可能性があるもの含め再現したまま）

- DamageUp（ダメージ倍率）は HitScan と Chain の武器にしか効かない
- アイテムのレベルアップの選択肢で、2番が出ない（ItemLevelUp_02 の番号が 3 になっている）
- Ball は消えても EnemyGenerator のリストから除かれず、敵の数の上限を押し上げる（グラフの「リスト数」が「生存数」より大きくなるのはこのため）
- Ball の転がる速さに上限がない
- フルオートの武器は、撃ち続けたまま弾が尽きるとリロードしない
- 武器のチャージ時間（chargeTime）は使われていない
- AutoTarget の Beam は壁を抜ける

ゲーム側でこれらが直ったら、シミュレータも合わせて直す必要があるので直したときは一報ください
