# 敵Phase（旧PhaseData方式）

`Assets > Create > EnemyGenerator > PhaseData` で作成し、Generatorの `Phases` に設定する。
各Phaseは `Start Time` の絶対時刻で切り替わる。敵構成・最低維持数・出現間隔をアセットで直接編集できる。

GameSceneは12組・合計36Phaseで、各組を次の順序に分けている。

- `Phase_XX`：phase1（通常）。以前の通常区間の敵構成・最低維持数・出現間隔を使用。
- `EXPhase_XX`：間のEX区間。中ボス候補だけを重みで選び、区間中に順次生成。`Is Ex Phase` を有効にし、直前の通常Phaseの実測DPSに応じたHP補正を維持。
- `Phase_XX_2`：phase2（大量出現）。以前の大群の敵構成を使用し、最低維持数と出現頻度に大群倍率を反映済み。

開始時刻は以前の通常・中ボス・大群の境界を引き継ぐ。通常30秒→EX10秒→大量25秒が基本。
Phase_02・02_B・03・03_Bは通常15秒→EX5秒→大量12.5秒。
既存の通常PhaseのGUIDを維持しているため、壁の色の演出も同じ時刻で切り替わる。

EXは旧方式の通常スポーンを使う。最低維持数は0とし、既存の雑魚数に左右されず出現間隔ごとに1体ずつ生成する。
初期の出現間隔は「以前の中ボス区間の秒数÷中ボス生成数」。位置を確保できなかった場合、その回の生成は見送る。
生成総数の管理やEX中の雑魚の追加生成は設けていない。生存中の敵はPhaseをまたいで残り、生成上限では旧仕様どおり遠い敵から入れ替える。

最後のPhaseは `Phase_09_2`（625秒開始）。エンドレスではこの設定で生成を続け、通常・EXへ戻らない。
時間制限ありの600秒終了は既存のTimerが管理する。アイテム用のPhase設定も従来どおり。

全Phaseが旧PhaseDataに戻ったため、BalanceSimでもそのまま読み込める。
`Tools > Enemy > 旧Phase構成を検証` でアセット参照・切替境界・DPS補正・最終Phaseの継続を確認できる。
